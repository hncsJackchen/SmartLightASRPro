## 产品介绍

智能开灯产品的**语音交互前端**：对着它说话即可开关灯，全程无需手动摸开关；配合 ESP-12F 主控的进门自动开灯，形成「自动 + 语音」双通道控制。

**使用场景**

- 双手提物、腾不出手摸开关的场合，用语音开灯 / 关灯。
- 玄关 / 门厅等进出频繁区域，语音作为自动感应的补充。

**触发场景**

| 场景 | 触发条件 | 动作 |
|---|---|---|
| 语音开灯 | 唤醒后说「打开灯光 / 开灯」 | 发 `ON`，播报执行结果 |
| 语音关灯 | 唤醒后说「关闭灯光 / 关灯」 | 发 `OFF`，播报执行结果 |
| 退出语音 | 唤醒后说「退出」 | 立即休眠，播退出提示音 |

> ASR-PRO 只做「听 → 说」；舵机、光照、测距、灯状态全部在 ESP-12F 侧。

## 1. 硬件接线

UART 对接 ESP-12F（9600 8N1）：

| ASR-PRO 引脚 | ESP-12F 引脚 | 说明 |
|---|---|---|
| TX（PB5，引脚 13） | RX（GPIO3，D9） | ASR → ESP |
| RX（PB6，引脚 14） | TX（GPIO1，D10） | ESP → ASR |
| GND | GND | 共地 |

> ASR-PRO 与 ESP-12F 同为 3.3V 供电，共地即可；麦克风、喇叭使用 ASR-PRO 配套外设。

## 2. 命令词与播报

| 命令词 | ID (`snid`) | 行为 |
|---|---|---|
| 「智能灯光」 | 0 | 唤醒词 |
| 「打开灯光」 | 1 | 发 `ON\n` |
| 「关闭灯光」 | 2 | 发 `OFF\n` |
| 「开灯」 | 3 | 发 `ON\n` |
| 「关灯」 | 4 | 发 `OFF\n` |
| 「退出」 | 5 | 立即休眠 |

播报语音（`//{playid:...}` 定义）：`已打开灯光` / `已关闭灯光` / `操作失败`，以及欢迎语、退出提示音。

### 3.2 关键 DSL

`.hd` 中的 `//{...}` 注释块是 IDE 解析的 **DSL**（不是普通注释）：

- `//{ID:n,keyword:"命令词",ASR:"打开灯光",ASRTO:""}` — 命令词定义，`ID` 即 `ASR_CODE()` 里的 `snid`。
- `//{playid:10003,voice:已打开灯光}` — 播报语音，由 `play_audio(10003)` 播放。
- 文件末尾 `/** edittype="asr_procode" */` 是 IDE 标记，须保留。

编辑这些块才能改变命令词 / 播报语；删除或破坏语法会静默改变固件。

## 4. 通信：与 ESP-12F 的 UART 协议

物理层：UART 9600 8N1，文本帧，以换行结尾（兼容 `\n` / `\r\n`）。详细契约见 [../SmartLight/doc/软件设计.md](../SmartLight/doc/软件设计.md) 第 6 节。

ASR-PRO → ESP-12F（指令）：

| 帧 | 含义 |
|---|---|
| `ON\n` | 打开灯光 |
| `OFF\n` | 关闭灯光 |

ESP-12F → ASR-PRO（响应）及播报语：

| 帧 | 含义 | 播报语 |
|---|---|---|
| `ON_OK\n` | 已执行开灯 | 已打开灯光 |
| `OFF_OK\n` | 已执行关灯 | 已关闭灯光 |
| `ERROR\n` | 执行出错 | 操作失败 |

> ASR-PRO 仅在主动发送指令后才等待一条对应响应；超过 2s 无响应按 `ERROR` 播报「操作失败」。
